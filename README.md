# Maneega AI Chat (ระบบแชต AI อัจฉริยะ)

เว็บแอปพลิเคชัน AI Chat สไตล์โมเดิร์น คลีน สวยงาม ออกแบบตาม UI/UX ต้นแบบของ Maneega โดยพัฒนาด้วย **Node.js + Express** พร้อมระบบจำลอง AI อัจฉริยะภาษาไทย/อังกฤษ และรองรับการเชื่อมต่อ API ภายนอก

---

## 🌟 จุดเด่นและฟีเจอร์หลัก (Features)

1. **ดีไซน์ถอดแบบจากภาพต้นฉบับ 100% (Pixel-Perfect UI)**
   - โทนสีและฟอนต์ Prompt / Plus Jakarta Sans สะอาดตา สบายตา
   - Sidebar ด้านข้างพร้อมปุ่ม **"+ เริ่มแชตใหม่"** (มีปุ่มลัด `⌘ K` หรือ `Ctrl + K`)
   - ระบบจัดหมวดหมู่ประวัติการคุย: **"วันนี้"** และ **"7 วันที่ผ่านมา"**
   - การ์ดแนะนำไอเดีย 4 แบบ:
     - ✏️ **เขียนให้น่าอ่าน** (ช่วยร่างอีเมลให้ดูเป็นมืออาชีพ)
     - 💡 **จุดประกายไอเดีย** (คิดคอนเทนต์ใหม่ ๆ สำหรับโซเชียลมีเดีย)
     - 📄 **สรุปให้เข้าใจง่าย** (เปลี่ยนเรื่องยาว ให้เหลือใจความสำคัญ)
     - 💻 **ช่วยเขียนโค้ด** (อธิบายโค้ดที่ซับซ้อนทีละขั้นตอน)
   - การ์ดอัปเกรด **"ไอเดียดี ๆ ไม่มีขีดจำกัด - ปลดล็อกกับ Pro"**
   - ส่วนท้ายระบุข้อความคำเตือนตามแบบ: *"Lamoon อาจให้ข้อมูลคลาดเคลื่อนได้ โปรดตรวจสอบข้อมูลสำคัญอีกครั้ง"*

2. **ระบบการสนทนาและการตอบกลับ (AI Chat Engine)**
   - **Real-time Typewriter Streaming (SSE)**: ตอบข้อความแบบพิมพ์สดลื่นไหล
   - **Markdown Parser ในตัว**: รองรับหัวข้อ, ตัวหนา, ลิสต์, ตาราง, บล็อกคำพูด และบล็อกโค้ดพร้อมปุ่ม **"คัดลอกโค้ด"**
   - **เครื่องมือจัดการข้อความคำตอบ**: คัดลอกข้อความ, กดถูกใจ/ไม่ถูกใจ, และปุ่ม **อ่านออกเสียง (Text-to-Speech)** ภาษาไทย
   - **ระบบเสียงพูด (Speech-to-Text)**: รองรับการกดไอคอนไมโครโฟนเพื่อพูดภาษาไทยแล้วแปลงเป็นข้อความ

3. **ฟังก์ชันขั้นสูงเพิ่มเติม**
   - 📎 **แนบไฟล์ (File Upload)**: รองรับการแนบรูปภาพ โค้ด เอกสาร พร้อมแสดงแท็กไฟล์และพรีวิว
   - 🔍 **ค้นหาแชต (Search Chat)**: ค้นหาคำหรือข้อความได้ทันทีทั้งหัวข้อและเนื้อหาในแชต
   - ⊞ **คลังของฉัน (Prompt Library)**: จัดการและเลือกใช้ Prompt สำเร็จรูป หรือเพิ่ม Prompt ใหม่ได้
   - ⚙️ **การตั้งค่า (Settings)**: รองรับการใส่ Google Gemini API Key หรือปรับแต่ง System Prompt ได้ตามใจชอบ
   - 📱 **Responsive**: รองรับการใช้งานทั้งบนหน้าจอ Desktop และมือถือ (Mobile Drawer)

## 📂 โครงสร้างโปรเจกต์ (Project Structure)

```
d:\AppServ\www\aichat\
├── package.json          # กำหนด dependencies และสคริปต์
├── server.js             # เซิร์ฟเวอร์ Node.js + Express API
├── .env.example          # ตัวอย่างไฟล์ Environment Variables
├── data/
│   ├── chats.json        # ฐานข้อมูลประวัติการสนทนา (JSON Storage)
│   ├── library.json      # คลังคำสั่งลัด / Prompts
│   └── settings.json     # การตั้งค่าระบบ
├── uploads/              # โฟลเดอร์จัดเก็บไฟล์ที่แนบ
└── public/
    ├── index.html        # หน้าเว็บหลัก
    ├── css/
    │   └── style.css     # สไตล์และแอนิเมชัน
    └── js/
        ├── app.js        # ตัวควบคุมหลัก (State, Events, API, Audio)
        └── markdown.js   # Parser แปลง Markdown เป็น HTML สวยงาม
```

## 🚀 วิธีการรันใช้งาน (How to Run)

### 1. ติดตั้ง Dependencies (ทำครั้งแรก)
```bash
npm install
```

### 2. รันเซิร์ฟเวอร์
```bash
npm start
```
หรือหากต้องการรันแบบ Auto-reload เมื่อแก้ไขโค้ด:
```bash
npm run dev
```

### 3. เปิดเบราว์เซอร์
เข้าใช้งานได้ที่:
```
http://localhost:3000
```
